## 怎么继续做

1. 首领数据集中在 data/bosses.js。
2. 样式在 assets/styles.css，交互在 assets/app.js。
3. 后续新增作战篇时，可以复制当前结构并拆成 weapons.html、warframes.html、open-world.html。
4. 视频链接都用 https://www.bilibili.com/video/BV.../ 或 Bilibili 搜索链接。
